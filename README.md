# Java Web App for Apache Tomcat

A simple, lightweight Java Servlet web application built with Maven, designed for deployment on Apache Tomcat.

## Prerequisites
* Java JDK 17 or higher
* Apache Maven 3.6+
* Apache Tomcat 10+ (or any Servlet 6.0 compatible container)
